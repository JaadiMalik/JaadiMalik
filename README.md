## Selected work

### 🚀 [SupplyChain Copilot](https://github.com/JaadiMalik/supplychain-copilot)
**Local-first AI for supply-chain and procurement decision support · Working prototype**

A practical operations assistant that combines **structured data analytics** with **supplier-document evidence**. It is designed to answer questions across purchase orders, shipments, inventory, contracts, and supplier records—while separating AI-generated explanations from rule-based business verification.

**Highlights**
- Queries operational datasets using SQL and DuckDB.
- Uses RAG to retrieve relevant supplier-document passages with supporting evidence.
- Resolves supplier aliases explicitly and applies deterministic checks for combined data-and-document questions.
- Provides a React dashboard, FastAPI backend, and local-model workflow.

**Stack:** `Python` `FastAPI` `React` `DuckDB` `ChromaDB` `Qwen` `RAG`

[Explore the project, architecture and screenshots →](https://github.com/JaadiMalik/supplychain-copilot)

<details>
<summary><strong>Example problem this project explores</strong></summary>

> Which open purchase orders belong to suppliers whose contracts include late-delivery penalties?

A useful answer requires joining structured purchase-order records to verified supplier identities and relevant contract clauses—not just asking an LLM to guess.

</details>
